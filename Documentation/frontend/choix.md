## INTRODUCTION
Le projet **GATEWAY** repose sur une stack moderne et performante pour garantir une expérience fluide, rapide et maintenable.  
Les technologies choisies : **Vite**, **TypeScript**, **React** et **Tailwind CSS** 
Ils répondent à des besoins précis de performance, de typage, de modularité et de design.

---

## VITE 
- **Rôle** : outil de build et de développement.
- **Pourquoi ce choix :**
  - Démarrage ultra rapide grâce à l’utilisation de **ESBuild**.
  - Rechargement instantané (HMR) pour un développement fluide.
  - Configuration simple et légère.
  - Compatible avec React, TypeScript et Tailwind sans surcouche complexe.
- **Avantage concret :**
  - Temps de compilation réduit.
  - Expérience développeur moderne et réactive.

---

## TYPESCRIPT 
- **Rôle** : langage de typage statique basé sur JavaScript.
- **Pourquoi ce choix :**
  - Sécurise le code grâce aux **types explicites**.
  - Facilite la maintenance et la collaboration.
  - Offre une meilleure **intégration IDE** (autocomplétion, vérification d’erreurs).
  - Compatible avec React et Vite sans configuration lourde.
- **Avantage concret :**
  - Réduction des bugs liés aux types.
  - Code plus clair, plus robuste et plus évolutif.

---

## REACT 
- **Rôle** : bibliothèque pour construire des interfaces utilisateur dynamiques.
- **Pourquoi ce choix :**
  - Composants réutilisables et modulaires.
  - Gestion efficace du DOM virtuel (Virtual DOM).
  - Large écosystème et communauté active.
  - Parfait pour les applications SPA comme GATEWAY.
- **Avantage concret :**
  - Structure claire du frontend.
  - Intégration facile avec le contexte global (ex : `ThemeContext`).
  - Possibilité d’utiliser des hooks (`useState`, `useEffect`, `useContext`) pour une logique propre et réactive.

---

## TAILWIND CSS 
- **Rôle** : framework CSS utilitaire pour le design rapide et cohérent.
- **Pourquoi ce choix :**
  - Syntaxe simple et expressive directement dans le JSX.
  - Personnalisation facile via `tailwind.config.js`.
  - Support du mode sombre (`darkMode: "class"`) intégré.
  - Réduction du CSS global : tout est géré par classes utilitaires.
- **Avantage concret :**
  - Rapidité de prototypage.
