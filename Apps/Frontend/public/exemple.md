# Dossier Public 

## Rôle
Ce dossier contient les ressources statiques qui ne doivent pas être traitées par le compilateur (Vite). Tout fichier placé ici sera copié tel quel à la racine du dossier de build (`dist/`).

## Contenu attendu
* **Favicon / Logos** : Icônes du site affichées dans l'onglet du navigateur.
* **robots.txt** : Instructions pour les robots d'indexation (SEO).
* **manifest.json** : Configuration des métadonnées pour les Progressive Web Apps (PWA).
* **Documentation statique** : Eventuels fichiers PDF ou ressources brutes accessibles via URL directe.
